> # Testing Player Types in a Gamified System
> 
> The objective of my research project is to assess how specific, predetermined types of players/users may interact with catered mechanics in a gamified system. This research is based on a previous study on player preference types, published as *["Digital Game Dynamics Preferences and Player Types"](https://doi.org/10.1111/jcc4.12181)* by *Jukka Vahlo, Johanna K Kaakinen, Suvi K. Holm,* and *Aki Koponen*. 
> 
> My study will utilize the seven main player types/clusters and their preferences established by this paper, as well as the five main 'game dynamics' identified by it.
> 
> By utilizing these preferences for specific game dynamics and catering towards specific player types, this project is intended to test for changes in engagement levels from players in a gamified system.
